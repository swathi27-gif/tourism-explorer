# 🌍 Tourism Explorer

Explore amazing tourist destinations with Tourism Explorer!

## ✨ Features
- 🔎 Search for tourist destinations
- 🏛️ Discover museums and historic sites
- 🌿 Explore nature spots
- 🗺️ Open locations in Google Maps
- 📍 Find attractions for your chosen destination

## 🛠️ Built With
- React
- JavaScript
- Vite
- Material UI
- Cloudflare Workers
- Geoapify API

## 🚀 About
Tourism Explorer is a hackathon project designed to make discovering tourist attractions easy and enjoyable.
